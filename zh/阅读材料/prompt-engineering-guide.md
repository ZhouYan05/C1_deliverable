## 提示技巧（Prompting Techniques）

提示词工程（Prompt Engineering）帮助我们有效地设计并改进提示词，从而在
大语言模型（LLM）的不同任务上取得更好的结果。

前面那些基础示例虽然有趣，但本节要介绍的是更高级的提示词工程技术——它们让我们
能够完成更复杂的任务，并提升 LLM 的可靠性与表现。

**本节要点**

提示词工程的核心不是"把话说得更漂亮"，而是**结构化地控制模型的行为**：

1. **明确任务**——说清楚要模型做什么，而不是只描述话题。
2. **给出格式**——需要 JSON 就指定 JSON，需要分点就指定分点。
3. **提供样例**——少样本提示（Few-shot）往往比抽象描述更有效。
4. **给足上下文**——模型只能看到你放进上下文窗口的内容。
